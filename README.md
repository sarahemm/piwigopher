# piwigopher
Gopher CGI mole interface to the Piwigo image gallery system

Allows viewing albums/categories and images from your Piwigo library, via a
gopher server supporting moles/CGI.

Example: gopher://sen.cx/1/cgi-bin/piwigopher

Setup
-----
0. Change PIWIGO_URL at the top of the piwigopher script to point to your
instance's URL.
0. Copy 'piwigopher' and 'piwigo-mini.rb' into your gopher CGI directory.
0. Ensure your gopher server has CGI enabled.
0. Browse to wherever you put the piwigopher file!
